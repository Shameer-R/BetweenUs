# BetweenUs

**Status: In Progress**

BetweenUs is a progressive web app I'm building for couples (my girlfriend and I mainly) to plan dates, keep track of movies and shows, save memories, and share experiences together.

I'm working on this project to build my React skills and gain more experience building a complete web app from scratch.

## Current Tech Stack
- React
- Javascript
- HTML + CSS
(Currently unsure about backend but I believe it'll be Node.js)

## Features
### Currently Implemented
- Navigation between different pages
- Date ideas page with modal to add new data ideas
- Marking date ideas as completed
- Deletion of date ideas

### Planned Features
- Date idea editing
- Saving data between sessions
- Movie and TV show watchlist
- Shared tasks and calendar
- Memories page
- User authentication and shared accounts (stretch goal)

*None of this is in any particular order*

## Getting Stared
1. Clone the repository: `https://github.com/Shameer-R/BetweenUs.git`
2. Navigate to the frontend: `cd BetweenUs/frontend`
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev`

## Project Goals 

My goal is to build a functional PWA that couples can use to organize activities and keep track of things they want to experience together. This app is mainly for me and my girlfriend but maybe in the future I can expand to add support for others accounts. I'm using this project to practice component-based development, state management, and working with a backend and database.
